Generated with Google Gemini (2.5 Flash Image) from prompts in the Obsidian
setup plan. Motif: a Poké-Ball fused with a pencil/paintbrush over a cream
sketchbook page.

| File | Size | Use |
|---|---|---|
| `icon.png` | 1024×1024 | Discord **application icon** (rendered as a circle). |
| `banner.png` | 680×240 | Discord **application banner** (App Directory / profile). |
| `icon-original-2048.jpg` | 2048×2048 | Full-res source for the icon. |
| `banner-original-3488x1216.jpg` | 3488×1216 | Full-res source for the banner. |

To upload: Discord Developer Portal → your app → **General Information**
(App Icon + Cover Image / banner). The bot avatar can be set under **Bot**.

Regenerate/resize with Pillow; keep icon square and banner at ~2.83:1.
